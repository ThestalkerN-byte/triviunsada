# Triviunsada

Trivia por carreras universitarias. El MVP corre entero en el navegador.

## Requisitos

Node.js 20 o superior.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí http://localhost:3000.

## Pruebas

```bash
npm test
```

## Export estático

```bash
npm run build
```

El sitio queda en `out/` y se puede publicar en Vercel, Netlify o GitHub Pages.
